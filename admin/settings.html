Cadangkan Pengaturan

Unduh pengaturan lokal sebagai file JSON untuk menyimpan salinan atau memindahkannya secara manual.

Impor Pengaturan

Pulihkan pengaturan dari file JSON yang sebelumnya diekspor menggunakan halaman ini.

Impor akan mengganti pengaturan identitas, invoice, dan daftar paket lokal yang sedang tersimpan. Ekspor backup lama terlebih dahulu sebelum melakukan impor.

Reset Pengaturan Lokal

Menghapus pengaturan yang disimpan oleh halaman ini dari browser dan mengembalikan nilai awal. Tindakan ini tidak menghapus database Supabase maupun data pada modul admin lain.
